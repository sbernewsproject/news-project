# news.mail.ru — Новости

Парсер новостей с news.mail.ru. Каждая статья сохраняется как отдельная запись.

## Как работает

Шаг `sitemap` делает всё: обходит страницу `/sitemap/`, получает список всех месяцев, затем для каждого месяца получает список дней, а для каждого дня — список статей. После этого парсит каждую статью и сохраняет полный текст.

| Шаг | URL | Что берём |
| --- | --- | --- |
| Список месяцев | `/sitemap/` | Ссылки на страницы месяцев |
| Список дней | `/sitemap/YYYY-month/` | Ссылки на страницы дней |
| Список статей | `/sitemap/YYYY-month/D/` | Ссылки на статьи |
| Статья | `/rubric/ID/` | HTML: title, body, author, date, source |

## Запуск

Все команды выполняются из корня репозитория.

Тест — первые N дней:
```bash
python3 parser/parser/main.py parser/mail.ru sitemap --limit 5
